# MR.Prints-Manager

MR Prints Manager is a private application developed for managing Allegro marketplace listings for MR Prints, a Polish 3D printing business.

Features

Reading and updating Allegro listings.

Managing product parameters and categories.

Automating bulk listing updates.

Access

This application is intended exclusively for internal use by MR Prints. It is not offered as a public service.

Version

1.0.0
